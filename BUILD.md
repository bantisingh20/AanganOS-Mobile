# AanganOS Mobile — Production Release Build (Android)

This produces a signed, size-optimised **universal release APK (~58 MB)** that installs on any
real Android phone (arm64-v8a + armeabi-v7a; emulator-only x86/x86_64 excluded).

> The `android/` folder is generated by `expo prebuild` and is gitignored. All reproducible build
> settings therefore live in tracked files (`app.config.ts`) or in the steps below. Do NOT rely on a
> local `android/` folder — regenerate it.

## 1. Prerequisites
- Node.js >= 20, npm
- JDK 17 (Temurin recommended)
- Android SDK (set `ANDROID_HOME` / `ANDROID_SDK_ROOT`), with NDK + CMake installed
- A release **keystore** (see §4). Never commit the keystore or its passwords.

## 2. Install dependencies
```
npm install
```

## 3. Generate the native Android project
```
npx expo prebuild --platform android --clean
```
`app.config.ts` already enables the size optimisations via `expo-build-properties`:
- `enableProguardInReleaseBuilds: true`   (R8 code shrinking)
- `enableShrinkResourcesInReleaseBuilds: true`  (unused resource shrinking)

## 4. Signing keystore (one-time, keep it SAFE forever)
Every production build AND every future update must use the SAME keystore. If lost, the app can
never be updated. Store it outside the repo and back it up.

Generate once (example — use your own secure passwords):
```
keytool -genkeypair -v -keystore release.keystore -alias aanganos \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass <STORE_PASSWORD> -keypass <KEY_PASSWORD> \
  -dname "CN=AanganOS, OU=Mobile, O=AanganOS, L=NA, ST=NA, C=IN"
```
Place `release.keystore` in `android/app/` (it is gitignored).

## 5. Restrict to ARM architectures (the main size win)
After prebuild, edit `android/gradle.properties` and set:
```
reactNativeArchitectures=armeabi-v7a,arm64-v8a
```
(Removing `x86,x86_64` drops two native-library copies — those are emulator-only.)

## 6. Build the signed universal APK (ARM-only, minified)
From the `android/` folder:
```
./gradlew :app:assembleRelease \
  -PenableAbiSplit=false \
  -ParmOnly=true \
  -PAANGANOS_RELEASE_STORE_FILE=release.keystore \
  -PAANGANOS_RELEASE_STORE_PASSWORD=<STORE_PASSWORD> \
  -PAANGANOS_RELEASE_KEY_ALIAS=aanganos \
  -PAANGANOS_RELEASE_KEY_PASSWORD=<KEY_PASSWORD> \
  --no-daemon
```
On Windows use `gradlew.bat` and quote each `-P...` argument.

Output:
```
android/app/build/outputs/apk/release/app-release.apk   (~58 MB)
```

### Build flags (defined in android/app/build.gradle after prebuild — see §7 if missing)
| Flag | Effect |
|------|--------|
| `armOnly=true` | Packages only `armeabi-v7a` + `arm64-v8a` native libs (via `ndk.abiFilters`). Biggest size win. |
| `enableAbiSplit=true` | Produces one smaller APK **per** architecture instead of a universal one. |
| `enableUniversalApk=true` | With split on, also emits a combined APK. |
| `AANGANOS_RELEASE_*` | Release signing (keystore path, passwords, alias). Absent → falls back to the debug key. |

## 7. If you regenerate android/ with `--clean`
`expo prebuild --clean` overwrites `android/app/build.gradle`, removing the custom `armOnly`
abiFilters block and the release signing config. Re-apply these two edits (they are the only manual
native changes; everything else comes from `app.config.ts`):

### 7a. Release signing — in `android/app/build.gradle`, inside `signingConfigs { }`:
```groovy
release {
    if (project.hasProperty('AANGANOS_RELEASE_STORE_FILE')) {
        storeFile file(AANGANOS_RELEASE_STORE_FILE)
        storePassword AANGANOS_RELEASE_STORE_PASSWORD
        keyAlias AANGANOS_RELEASE_KEY_ALIAS
        keyPassword AANGANOS_RELEASE_KEY_PASSWORD
    }
}
```
and in `buildTypes { release { ... } }` set:
```groovy
signingConfig project.hasProperty('AANGANOS_RELEASE_STORE_FILE') ? signingConfigs.release : signingConfigs.debug
```

### 7b. ARM-only filter — in `android/app/build.gradle`, inside `defaultConfig { }`:
```groovy
if ((findProperty('armOnly') ?: 'false').toBoolean()) {
    ndk {
        abiFilters "armeabi-v7a", "arm64-v8a"
    }
}
```

### 7c. (optional) ABI split block — inside `android { }`:
```groovy
splits {
    abi {
        enable = (findProperty('enableAbiSplit') ?: 'false').toBoolean()
        reset()
        include "armeabi-v7a", "arm64-v8a"
        universalApk = (findProperty('enableUniversalApk') ?: 'false').toBoolean()
    }
}
```

## 8. Environment / API URL
The production API URL comes from `.env.production`:
```
EXPO_PUBLIC_API_BASE_URL=https://aanganosapi.sharcnix.com
```
(All `.env*` except `.env.example` are gitignored. Share the production values securely.)

## 9. Verify the result
```
# size
ls -lh android/app/build/outputs/apk/release/app-release.apk

# signature (use apksigner from Android SDK build-tools)
apksigner verify --print-certs android/app/build/outputs/apk/release/app-release.apk
```
Expect ~58 MB and certificate `CN=AanganOS`.

## 10. Google Play (optional)
For the Play Store, build an **AAB** instead and let Play generate per-device downloads:
```
./gradlew :app:bundleRelease -ParmOnly=true -PAANGANOS_RELEASE_STORE_FILE=release.keystore ...
```
Upload `android/app/build/outputs/bundle/release/app-release.aab`.
